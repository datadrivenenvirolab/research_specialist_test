# Data-Driven EnviroLab Technical Assignment

## Assignment A: Company Data Matching

This assignment combines Forbes 2000 company data with NetZero Tracker data. The analysis includes company-name standardization, matching, and merging.

## Assignment B: ClimActor Data Analysis

This assignment explores climate actor data through visualizations of greenhouse gas emissions, climate plans and targets, initiatives, sector-level emissions, and geographic patterns.

## Files

- `Assignment_A.R`: Code for Assignment A.
- `Assignment_B.R`: Code for Assignment B.
- `data/`: Datasets used by the analyses.

## Running the Code

Run the R scripts in RStudio. Ensure the required datasets are in the appropriate locations, making sure to update file paths. Install any required R packages if they are not already installed.
