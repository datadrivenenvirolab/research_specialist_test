Mary Mungai ClimActor v2 Analysis 

Description
This project includes raw datasets in CSV files, an RMarkdown file of code, a PowerPoint, Word document and several images. The RMarkdown file should be easily read from beginning to end, as the relevant libraries are included in the code chunks as they come up, including tidyverse, dplyr, gt, and sf. Please consider downloading the CSV files to your own computer then replacing the link in read_csv with one relevant locally. Please also note that the PowerPoint contains my slides, and the Word document contains my answers to the questions and the explanation of my workflow.
